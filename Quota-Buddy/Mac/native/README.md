# Quota Tide Companion（macOS 原生浮窗）

这是原生 Mac 浮窗，而不是网页：它保持一个无边框、置顶的小面板，并每 0.45 秒查找 Codex 的小尺寸宠物窗口，自动放到宠物下方。

它不读取页面内容、账号信息或对话记录；只读取窗口尺寸/位置来跟随宠物。若 Codex 宠物被隐藏，浮窗停在最后一次可用位置。菜单栏 `✦` 可暂停或恢复跟随，并打开完整网页观测台。

首次运行请使用项目根目录的 `start-native.command`。它会启动只读本机额度服务、编译此原生外壳并启动浮窗。

> macOS 对其他应用窗口的可见性因系统版本而异。如果浮窗没有贴到宠物旁，先确认宠物可见；若仍然无法识别，后续可启用“辅助功能”权限增强窗口识别，而不读取任何内容。
