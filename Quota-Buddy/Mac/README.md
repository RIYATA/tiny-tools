# Quota Tide

一个只在本机运行的原生 Mac Codex 额度伴侣：无边框置顶浮窗会尝试贴着 Codex 宠物跟随。

## 启动方式

最完整的方式（推荐）：

```bash
cd "/Users/yinghuo/Desktop/我的主页/02_工具产品/Quota-Buddy/Mac"
./start-native.command
```

它会启动本机只读服务，并打开置顶的 Mac 小浮窗。菜单栏 `✦` 可以刷新额度、暂停跟随或退出。

## 数据与隐私

- 通过本机 `codex app-server` 的只读额度请求获取 5 小时额度、周额度、下次重置时间和可用重置次数。
- 如果本机服务暂不可用，会退回读取本机 Codex 运行记录；两者都不可用时会明确显示离线状态。
- 不读取、保存或上传账号密码、令牌、对话内容或个人文件。

## 交互

- 点击浮窗右上角的刷新符号：读取真实额度。
- 直接拖动浮窗：移动它；菜单栏 `✦` 可以暂停/恢复自动跟随。
- 浮窗会尝试识别 Codex 的小尺寸宠物窗口并贴在其下方；找不到时停在最后一次可用位置。
