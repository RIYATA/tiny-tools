## Quota Buddy

Quota Buddy 由本机只读额度服务和原生 macOS 浮窗组成。它优先通过本机 `codex app-server` 获取额度信息，服务不可用时会回退读取本机 Codex 运行记录。

项目不会上传账号密码、令牌、对话内容或个人文件。依赖目录、构建产物和原生编译文件均不纳入版本控制。
